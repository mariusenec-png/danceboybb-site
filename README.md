# danceboybb.com

Link hub website for DanceboyBB (live streams, gaming and socials).

- `index.html` – the whole page (styles + script inline). Links, colours and floating bricks are configured at the top of the `<script>` block (`LINKS`, `BRICKS`).
- `avatar.webp` – profile picture shown in the hero.
- `CNAME` – custom domain for GitHub Pages.

Hosted on GitHub Pages, DNS on Cloudflare.
